\topic{3. Extract Python functions and test (22--35 min)}
\begin{itemize}
  \item Extract model and residuals to \code{model.py}; roots to \code{solve.py}; sweep to \code{sweep.py}; figure to \code{plotting.py}.

\textbf{Gate 3:} Tests pass; extracted values match the pre-refactor baseline. Commit the code and tests.

\topic{4. Extend one analysis (35--40 min; continue later)}
\begin{itemize}
  \item Choose \textbf{one}: finer coolant grid; heat-transfer \code{UA}; feed temperature \code{Tf}; or denser solver guesses.
  \item Keep the nominal case as a control. Save a runnable script and result under \code{results/extensions/}.
  \item Add a test and a two-sentence interpretation: what the result supports, and what remains uncertain.
\end{itemize}
