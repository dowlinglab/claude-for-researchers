\heading{Part 1: build a project you can resume}{Summary and Workshop 1 \hfill 28 September 2026}
\textbf{What Part 1 covered.} An agent can inspect and edit a real workspace, run checks, and use Git history. A repository preserves changes and invites review. Concise \code{AGENTS.md} or \code{CLAUDE.md} gives an agent project context; it cannot certify a result. The research workflow is \textbf{inspect $\rightarrow$ run $\rightarrow$ audit $\rightarrow$ save a baseline $\rightarrow$ refactor $\rightarrow$ test $\rightarrow$ extend}. Record the environment and commands so a colleague can resume without your chat.

\textbf{Our case.} You inherit a cooled-reactor notebook and parameter file. The model may have multiple steady states at one operating condition. A solver result needs convergence and residual checks. Repeating a run checks reproducibility; it does not prove model validity, stability, or that all roots were found.

\textbf{The four gates:} 1 Git repository and original commit; 2 Conda, fresh run, and audit; 3 extracted functions with docstrings and tests; 4 one new analysis with a preserved control. Save the gate you reached at minute 40. The rest is continuation work between sessions.

\textbf{Ask, verify, record.} Have an agent map inputs to outputs, explain where a number came from, and propose a bounded next step. Read its cited source and inspect the diff. Save the checked result, the test command, and the open question in the repository.

\topic{Workshop 1: start from the notebook handoff}
\textbf{1. Download and initialize (0--10 min).} Open \href{https://github.com/dowlinglab/claude-for-researchers/blob/main/resources/workshops/cstr/workshop1_notebook.zip}{\texttt{workshop1\_notebook.zip}} at \repourl. Choose \textbf{Download raw file}, unzip, and open a terminal in \code{cstr-project/}. It holds a notebook, YAML parameters, and an empty results folder. Create an empty \textbf{private} GitHub repo named \code{cstr-project}; use its URL below.

\code{git init}\quad\code{git branch -M main}\\
\code{git add README.md notebooks data results/.gitkeep}\\
\code{git commit -m "Import inherited reactor notebook"}\\
\code{git remote add origin YOUR-PRIVATE-REPOSITORY-URL}\\
\code{git push -u origin main}\quad\code{git switch -c workshop1}

Check \code{git log -1 --oneline}, \code{git remote -v}, and \code{git status --short}. If push fails, continue locally and record the blocker.

\textbf{2. Create Conda environment (10--22 min).} If \code{conda --version} fails, install Miniconda (\url{https://docs.anaconda.com/miniconda/}) and reopen the terminal. Ask your agent to read the notebook imports and draft \code{environment.yml} with Python, NumPy, SciPy, pandas, matplotlib, JupyterLab, and pytest. Check its list yourself. A fallback file is at \code{resources/workshops/cstr/environment.yml}; remove its \code{-e .} install because this handoff has no package yet.

\code{conda env create -f environment.yml}\\
\code{conda activate cstr-workshop}\quad\code{jupyter lab}

Start Jupyter from \code{cstr-project/}. Select the environment kernel, then \textbf{Restart Kernel and Run All Cells}. Confirm \code{results/steady_states.csv} and \code{results/steady_state_locus.png}. If setup is slow, save the exact error or pending command and continue with a paired audit.
