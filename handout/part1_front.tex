\heading{Part 1: build a project you can resume}{Summary and Activity 1 \hfill 28 September 2026}
\topic{What we covered}
\begin{itemize}
  \item Agents can inspect files, edit code, run checks, and use Git history.
  \item Git records changes. Short \code{AGENTS.md} or \code{CLAUDE.md} files give agents project context.
  \item Work in order: \textbf{inspect $\rightarrow$ run $\rightarrow$ audit $\rightarrow$ save a baseline $\rightarrow$ refactor $\rightarrow$ test $\rightarrow$ extend}.
  \item \textbf{Ask $\rightarrow$ inspect $\rightarrow$ verify $\rightarrow$ iterate}, not prompt $\rightarrow$ trust $\rightarrow$ done. Check the agent's claims and diffs yourself.
\end{itemize}
\topic{The reactor case}
\begin{itemize}
  \item An inherited cooled-reactor notebook may find several steady states at one coolant temperature.
  \item Check solver convergence and residuals. A repeatable result does not prove model validity, stability, or that every root was found.
\end{itemize}

\topic{Activity 1: turn a folder into a GitHub repository}
\textbf{Goal.} End with a well-organized repository for the inherited notebook, on your computer and on GitHub, that you can explain. You do not need to know Git. Claude will teach you as it works. Your job is to ask, inspect, and verify.

\textbf{Get started}
\begin{itemize}
  \item \href{https://github.com/dowlinglab/claude-for-researchers/releases/latest/download/workshop1_activity.zip}{Download the ZIP} and unzip it. Open the \code{cstr-project/} folder itself in Claude, not a single file.
  \item Have a GitHub account ready. GitHub Desktop is optional; Claude can guide either route.
\end{itemize}

\textbf{A starter prompt} (change the wording freely)
\promptbox{I want to turn this folder into a clean GitHub repository. I am new to Git and GitHub. Please walk me through the process step by step using good practices. Start by inspecting the folder. Before each major step, explain what it accomplishes, and stop periodically so I can inspect what happened and ask questions.}

\textbf{The mental model.} A folder of files $\rightarrow$ a repository that records its history on your computer $\rightarrow$ a copy of that repository on GitHub. You are building that chain, one explained step at a time.

\topic{Words you will hear}
\renewcommand{\arraystretch}{1.1}
\begin{tabularx}{\linewidth}{@{}p{1.15in}X@{}}
\textbf{Repository} & A project folder plus the history Git keeps about it.\\
\textbf{Root} & The folder that contains the repository's \code{.git} folder.\\
\textbf{Commit} & A labeled checkpoint of the project, with a message.\\
\textbf{.gitignore} & A list of files Git should skip.\\
\textbf{GitHub} & A website that hosts a copy of your repository.\\
\textbf{Push, pull} & Send commits to GitHub, or bring them back.\\
\end{tabularx}
