# Talk outline

This file originally held the lifecycle-based planning outline. The final talk now uses the structure below; the complete 52-slide sequence is in [`slides/storyboard.md`](slides/storyboard.md). The superseded detailed outline remains in Git history through commit `2c55c74`.

The seminar slot is one hour: approximately 40 minutes of presentation and 20 minutes of questions.

| Section | Purpose |
|---|---|
| Prologue: Tinker | Start with a concrete project, state the thesis, and introduce the companion repository |
| Act I: Understand | Establish version control, durable context, and an idea-first literature workflow |
| Act II: Build | Turn research artifacts into reproducible software and documents |
| Act III: Challenge | Audit claims, reproduce inherited work, and make workflows more robust |
| Epilogue: Trust | Address policy, responsibility, recurring habits, hobbies, and next steps |

Tasks 1–7 form the research workflow. Task 8 is a deliberately lighter hobby extension. The talk's central message is that AI becomes more useful when it works inside a deliberate, reproducible, and auditable workflow whose state lives in files and Git rather than in one chat session.
