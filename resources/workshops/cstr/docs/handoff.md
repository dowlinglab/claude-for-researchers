# Handoff

Fill these five items at every stopping point. Delete guidance once filled.
State **complete session exercise** or **partial checkpoint** in item 3. Keep
agent checks separate from human confirmation; do not list future checks as run.

1. **Evidence commit:** hash of the commit saved before this handoff; branch,
   date, evidence paths, and any uncommitted work. This is not the handoff's own
   future commit.
2. **Producing command:** exact command(s) and working directory; for a report,
   source filename and whether a build occurred after its last edit.
3. **Checks actually completed:** comparison result, source locations inspected,
   what each establishes, and who checked it (agent / participant). For an audit,
   link the original quotes, verdicts and proposed/applied revision.
4. **Unchecked or blocked:** missing evidence, pending human review, limitations,
   and any source-only/revised-PDF-not-built status. Use “none” only if true.
5. **Next action:** one concrete step someone can perform without the chat.
