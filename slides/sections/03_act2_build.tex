\begin{frame}{Task 4 --- the recipe, in the order it actually happened}
  \ndlogonote{\scriptsize\texttt{resources/practices/\\scientific\_computing\_workflow.md}}
  \begin{center}
  \begin{enumerate} \small \setlength\itemsep{0.2em}
    \item Bootstrap the package
    \item Build a regression harness \textit{before} touching the algorithm
    \item Decompose, generalize, and port the paper's example
    \item Reproduce every figure, then document
    \item Reproduce every \textit{result} from scratch --- a discrepancy turned up
    \item Root-cause it: a real bug, confirmed to four decimal places$^\ast$
    \item Harden for robustness before publishing$^\ast$
    \item A full pass on hygiene, types, and test coverage$^\ast$
    \item A last pass on docs, tests, and comments$^\ast$
    \item Release
  \end{enumerate}
  \end{center}
  \vspace{0.15em}
  \begin{center}
    \scriptsize $^\ast$ added to the plan only after the step before it finished
  \end{center}
\end{frame}

\begin{frame}[fragile]{Best practices: review the diff, verify every revision}
  \ndlogonote{\scriptsize\texttt{resources/scripts/latexdiff\_check.sh}}
  \vfill
  {\scriptsize A generic, illustrative diff --- not a real commit.}
  \begin{lstlisting}
- df_all = pd.concat([load(f) for f in glob("data/*.csv")])
+ df_run = load(f"data/{run_id}.csv")
  \end{lstlisting}
  \vspace{0.4em}
  \begin{center}
    An AI-written summary says ``refactored the pipeline.'' The diff says what actually changed --- read it, not the summary.
  \end{center}
  \vspace{0.6em}
  \begin{center}
    \texttt{latexdiff} against the last commit, word-level, catches what a normal re-read misses --- for a proposal, a manuscript, either one.
  \end{center}
