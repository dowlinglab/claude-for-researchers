\begin{frame}{Ask Claude to teach you as it works}
  \vfill
  \begin{center}
    \begin{tikzpicture}
      \node[nd box, text width=0.86\linewidth, inner sep=10pt, align=left, font=\normalsize] {\hyphenpenalty=10000\relax
        I want to turn this folder into a clean GitHub repository. I am new to Git and GitHub. Please walk me through the process step by step using good practices. Start by inspecting the folder.     \end{tikzpicture}
  \end{center}
  \vspace{0.9em}
  \begin{center}
    \slidepoint{\textbf{Ask} $\rightarrow$ \textbf{inspect} $\rightarrow$ \textbf{verify} $\rightarrow$ \textbf{iterate}}\\[0.6em]
    {\small Ask questions whenever a word is new. Ask how to undo a step before you take it.}
  \end{center}
  \vspace{1.6cm plus 1fill}
\end{frame}
\note{Adapt the wording; it is a starting point, not a script. STOP TALKING now. The 45-minute work block is the main event of the session. Walk the room, look at screens, and ask what Claude just explained rather than answering the Git question yourself. Watch for two things: someone who opened the wrong folder as the workspace, and someone who accepts every step without reading it. Do not present a command sequence.}

\begin{frame}{You are done when you can explain what happened}
  \vfill
  \begin{columns}[c]
    \begin{column}{0.55\textwidth}
      \begin{itemize}\small\setlength\itemsep{0.55em}
        \item I know which folder is the repository root.
        \item I understand what Git tracks and what it ignores.
        \item I have a first commit that records the starting point.
        \item I can say how my local repository differs from GitHub.
        \item The repository is on GitHub.
        \item I can ask Claude to explain the current state.
      \end{itemize}
    \end{column}
    \begin{column}{0.41\textwidth}
      \textbf{Stuck? Ask Claude:}
      \begin{itemize}\small\setlength\itemsep{0.45em}
        \item ``Explain the last step without assuming I know Git.''
        \item ``How could I undo this?''
        \item ``Show me what Git thinks has changed.''
      \end{itemize}
      \vspace{0.6em}
      {\small\textbf{Finished early?} Stay in the same conversation and ask Claude to run and check the notebook.}
    \end{column}
  \end{columns}
  \vspace{1.6cm plus 1fill}
\end{frame}
\note{Leave this frame up while people work. After five minutes stuck on a tool, pair people up. Authentication failures are common: a local repository with the push pending is an acceptable checkpoint. The early-finisher path is the old steps two to four (run and audit the notebook, extract functions, try an extension), which we now leave to the conversation instead of a recipe.}
