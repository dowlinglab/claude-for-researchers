\begin{frame}{The filesystem is the source of truth}
  \vfill
  \begin{columns}[t]
    \begin{column}{0.46\textwidth}
      \begin{center}\textbf{A conversation}\end{center}
      \begin{itemize}
        \item not versioned
        \item not shared with collaborators
        \item not searchable next year
        \item gone when the session ends
      \end{itemize}
    \end{column}
    \begin{column}{0.46\textwidth}
      \begin{center}\textbf{A repository}\end{center}
      \begin{itemize}
        \item versioned
        \item shared by construction
        \item greppable % Instead say "searchable history"?
        \item outlives everyone involved
      \end{itemize}
    \end{column}
  \end{columns}
  Most important advice for today --- use \textbf{version control}:
  \begin{itemize}
  	\item Provides an auditable history of your code
  	\item Code stopped working? Version control becomes a time machine
  	\item Getting started is easy: create a GitHub account, apply for \href{https://github.com/education}{education free upgrades}, watch a \href{https://youtu.be/a9u2yZvsqHA?si=Tose1lV36yNAaf-q}{YouTube tutorial}, install \href{https://desktop.github.com/download/}{GitHub Desktop}.
  \end{itemize}
  \vfill
\end{frame}
